# liligu.com

Source for Lili Gu's personal website, served by GitHub Pages.

- `index.html` — the whole site (one page)
- `img/` — photos, film stills, and Tim's watercolor header and dividers

## Editing
The site is split into pages (Home, Film, Other work, About, Press, Contact), all generated from one source file.
Edit `src/site.html`, then run `python3 build.py` to regenerate the pages, and commit everything.
